# Third-party material

Project MIT licensing applies to original code, not source documentation or model weights. The evaluation dataset includes PostgreSQL excerpts: retain [the complete PostgreSQL notice](evals/POSTGRESQL-NOTICE.txt) and manifest provenance. Raw source captures are ignored by Git. Original fictional evaluation fixtures use CC0-1.0 as identified in `evals/fixtures/NOTICE.txt`.

Python/JavaScript dependencies are locked in uv.lock and apps/web/package-lock.json and retain their own notices. PyMuPDF is not used. Cross-encoder weights are downloaded separately; Ollama models are installed separately. No model weights are included in Git or the application image. Gemma has model-specific Google terms, not MIT. A comprehensive transitive-license/vulnerability audit has not been completed; no compliance certification is claimed.
