# Data sources

The local benchmark uses 24 pages from the official PostgreSQL documentation archives for versions 18.7 and 19.0. The [source manifest](../configs/source-manifest.json) records captured pages, versions and hashes. PostgreSQL excerpts retain their license notice. Private uploads and model weights are not redistributed.

The [original assessment](planning/DATA_SOURCE_ASSESSMENT.md) records the selection criteria and alternatives. See [evaluation methodology](evaluation-report.md) for how the corpus is used and its review limits.
